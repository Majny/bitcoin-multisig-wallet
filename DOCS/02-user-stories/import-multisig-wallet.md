# User story: Import multisig peněženky

## Popis
Jako **uživatel** si chci do aplikace importovat existující multisig peněženku pomocí descriptoru, abych mohl spravovat prostředky a podepisovat transakce této peněženky.

## Důvod
Multisig peněženky vyžadují speciální nastavení, aby bylo možné je používat.

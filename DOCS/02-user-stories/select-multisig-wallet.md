# User story: Výběr multisig peněženky

## Popis
Jako **uživatel** multisig peněženky si chci vybrat konkrétní multisig peněženku, abych mohl spravovat její PSBT transakce.

## Důvod
Můžu mít více multisig peněženek a potřebuji rychle přepínat mezi nimi, abych mohl pracovat s odpovídajícími transakcemi a podpisy.

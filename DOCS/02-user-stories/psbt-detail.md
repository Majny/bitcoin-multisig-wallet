# User story: Detail PSBT (PSBT Detail)

## Popis
Jako **uživatel** multisig peněženky chci vidět detail konkrétní PSBT transakce,  
abych mohl zkontrolovat její parametry a zjistit stav podpisů.

## Důvod
Potřebuji zkontrolovat, jaká částka se odesílá, na jakou adresu a kolik podpisů již bylo připojeno,  
abych mohl rozhodnout, jestli PSBT podepíšu, exportuji nebo ji nechám na později.

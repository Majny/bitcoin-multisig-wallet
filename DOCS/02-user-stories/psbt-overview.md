# User story: Seznam PSBTs

## Popis
Jako **uživatel** multisig peněženky chci vidět seznam všech rozpracovaných PSBT transakcí, abych mohl sledovat jejich stav, podepisovat je nebo je exportovat.

## Důvod
PSBT transakce vyžadují více podpisů, kvůli tomu potřebuji přehled, ve kterém vidím, které transakce čekají na podpis nebo jsou dokončené.
